Local investigation studio

Preserve the intelligence.

REE is a Mac-first studio on the REA analysis engine. Drop a file, paste a link you are allowed to fetch, or open a path. A ready route reads the artifact. Evidence stays on your machine.

Quick start Read the README

What REE does

Studio

One front door

Drop a file or folder, or paste a link. The fetch plan is shown before any request. The download is not executed.

Evidence

Saved records

Findings point at Evidence ids. The architecture graph copies stored relationships. A static edge is not an observed execution.

Mac app

Unsigned REE.app

Build it from this checkout with node ree.mjs app build. It listens on 127.0.0.1. It does not install Ghidra, IDA, or Hopper.

Engine

REA underneath

The CLI and MCP contracts stay the inherited REA engine from morluto/rea. REE does not replace them and is not the rea-agents package.

Investigation Studio

Simple Mode labels are Front door, Analyze, Findings, Board, and Build. Analyze is the recorded engine timeline. Advanced adds Evidence rebuild, Overview, Intake, Readiness, Evidence, Graph, Research, Experiment, and Report. Projects sit in the rail. Summary diff is an API and a research stage, not a separate navigation item.

Surface What you get
Projects A local project is created when you drop a file or plan a link, then resumed from the rail.
Front door Copy and classify a drop. A link lists URLs, byte limit, time limit, and destination before the fetch.
Analyze Recorded engine progress and Evidence facts. Replay walks the saved timeline. It does not invent stages.
Board and Build Ingest a Scout target or an outside-in spec, then scaffold a clean-room folder and a dry-run handoff. Scores are not invented and original source is not copied.
Artifact intake Choose a ready route. Classification reads a directory listing or the first bytes. It does not launch the target.
Architecture graph Stored edges only. Open recorded source when the path stays inside a directory target.
Evidence Search the saved application graph. A hit is a recorded relationship.
Experiment lab One approved probe of experiments/rel-first-lab, query bridge. The capture is not merged into static Evidence.
Summary diff Compare two run summaries and application-graph edge ids. It is not an REA version comparison.
Report Markdown that restates saved records. Save writes REE_STUDIO_REPORT.md beside the project.

From intake to report

outside-in does not enter this path. It writes a behavior spec from public documents and does not mint Evidence ids.

Format matrix

The studio runs a route only when that route is ready on this machine. A tool on PATH is not the same as a configured absolute path.

Quick start

Node 24 is required for the pinned toolchain. .nvmrc is 24.18.0. 

git clone https://github.com/gryszzz/reverse-engineer-everything.git
cd reverse-engineer-everything
nvm use 24
npm ci
npm run build:cached
node ree.mjs doctor
node ree.mjs studio --open

doctor and an empty studio also run on the engine range ^22.19.0 || ^24.11.0 || >=26.0.0. The analyzer is pinned to Node 24.

Mac app

node ree.mjs app build then node ree.mjs app install.

The build sets SDKROOT from xcrun --sdk macosx --show-sdk-path and passes that SDK to swiftc. Without it, a compiler on PATH can fail to load the standard library for arm64-apple-macos12.0.

The bundle is unsigned. If macOS blocks the first open, right-click REE.app, choose Open, then Open. Gatekeeper stays on.

Outside-in

Opt-in. When you do not have the code, name the public https documents and REE writes a behavior spec. It is not part of the studio, and it does not call REA. 

node ree.mjs outside-in \
  --name "Widget Cloud" \
  --url https://widgets.example/ \
  --docs https://widgets.example/openapi.yaml \
  --out /tmp/widgets-spec \
  --json

Public documents only

No cookies, no Authorization header, no login, no headless browser. robots.txt is obeyed. Redirects are not followed.

Clean-room spec

Quotes are at most 160 characters. A similarity guard redacts longer unmarked verbatim runs. Remote summarizers are refused.

Not Evidence

The spec does not create Evidence ids. Source and binary filenames are not fetched and are not decompiled.

Roadmap

The theater, the evidence rebuild, and the clean-room build are in this checkout. Actions and exports, and headless ree serve, are not commands yet.

In this checkout

Live Investigation Theater

A JavaScript analysis streams engine progress and Evidence facts. Replay walks that saved timeline. It does not invent stages.

In this checkout

Rebuild Studio

Advanced, labeled Evidence rebuild. Recovered module identities sit beside reconstructed stubs. The engine does not record a numeric match score, so verification stays unverified. Source text is not copied.

In this checkout

Clean-room Build

Board ingests a Scout target or an outside-in spec and does not invent scores. Build writes a new folder, declaration tests, and a dry-run handoff. It does not copy original source, notify Blast, call Guard, or copy into Vault.

Planned

Actions and exports

The report can be saved as Markdown beside the project. There is no general export palette.

Planned

Headless ree serve

The loopback server is node ree.mjs studio. There is no ree serve command.
