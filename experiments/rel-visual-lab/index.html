New to computer language? Open the 60-second dictionary (plain English) ↗
JavaScript
A language for writing instructions a computer can follow. Our tiny search program is written in it.
File
A named piece of a project. Think of a labeled drawer holding instructions or information.
Import
One file borrowing something from another file. REE can help trace these links.
Function
A reusable set of instructions: give it an input and it does a job.
Ranking
The rule that decides which search result should appear first.
Evidence
A specific observation or source location that supports a claim—not a confident guess.
Static analysis
Reading and mapping code without running the target program.
Runtime
What you can observe when a program actually executes.
Codex + MCP
Codex is the AI coding agent. MCP lets it ask tools like REA to investigate and return findings.
