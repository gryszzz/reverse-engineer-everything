# REE accuracy bench

These fixtures are source-owned. They are not third-party programs. `experiments/ree-bench/ground-truth.json` lists modules, functions, imports, calls, endpoints, strings, and behaviors read from the fixture source and public pages. `node ree.mjs bench` runs REE on each fixture and scores precision and recall against that file. `desk/` is a separate owned outside-in fixture for rebuild coverage. It is not a bench case. CI fails when fewer than 80% of its features pass their behavior tests. Thresholds live in `thresholds.json`. A false claim fails the run. Recall for calls, static behaviors, and native string literals is gated on these fixtures.

Call keys are `callerPath:callerName->calleePath:calleeName` for a resolved `calls` edge. Behavior keys are `module:function kind detail` for a fact inferred from syntax, with confidence and a limitation. A behavior marked observed is a provenance failure. Native strings are NUL-terminated printable ASCII from file-backed `.rodata`, `.rodata.*`, and `.data`, with a file offset that includes the terminating NUL. The native cases compile `native/fixture.c` with `gcc -nostdlib -static -O0 -Wl,-e,entry`. `native-stripped` then runs `strip --strip-all`. Both need `REA_PWNTOOLS_PYTHON` pointing at a Python with pwntools 4.15.0, pyelftools 0.33, and Unicorn 2.1.2. REE does not install those packages. The archive case packs `js-app` into an ASAR at run time.

Go and Rust cases write owned ELF, PE, and thin Mach-O images at run time with `tests/fixtures/go/image.ts` and `tests/fixtures/rust/image.ts`. They are not third-party binaries and they are not committed. Go keys are the embedded module path, the main module path, `path version` dependencies, and the compiler string `go1.26.0`. Rust keys are `name version` packages, `from->to` dependency edges, and the inferred `/rustc/<40-hex>/` hash. A rustc hash marked observed is a provenance failure. PE resource keys are `type/name/language`, with a quoted name when the identity is a string. `go-elf-no-buildinfo` expects no identities and requires the engine limitation that absent metadata does not prove the file is not Go. `macho-host-symbols` runs `inspect-macho` on the owned thin image. On a host without Apple tools the case passes only when the failure text is reported as partial. It does not invent symbol names. `fat-macho` and `not-a-binary` pass only when `inspect-go-binary` returns `unsupported_target` with a message. An empty provider result fails the bench.

`statistics.modules` counts bundler registrations. The bench reads source-module graph nodes instead.

`docs/` is an owned public-docs folder: OpenAPI, an HTML reference, Markdown, and a pricing page. `node ree.mjs bench` runs `ingest-docs` on it. Ground truth is the headings, endpoint lines, resource paths, quotes, and tier names that are in those files. `skip-me.js`, `notes.txt`, and `a/b/c/d/e/` are outside the ingest and are not expected findings. The walker also skips `node_modules`; that directory is not part of this fixture. A URL ingest is not part of this case. Rate-limit amounts stay in the behavior spec; the scorer has no rate-limit type.

These recoveries stay out of the ground truth because the static facts do not establish them:

- A destructured dynamic import (`const { name } = await import(...)`), a re-export, a computed callee, `eval` / `Function`, or a method reached through a later assignment.
- Control-flow postconditions that are not a direct `return`, and any claim that a behavior ran.
- String bytes outside file-backed `.rodata` and `.data`, non-ASCII text, and literals past the 256-string / 256-byte / 1 MiB scan bound.
- Function names in a stripped symbol table. `native-stripped` expects no function findings.
- `node:fs` `readFile` and `readFileSync` are one `io readFile` fact. External `node:` modules are not resolved calls.
